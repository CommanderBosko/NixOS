## Recent Decisions

_Older entries are in [project-state-decisions-archive.md](project-state-decisions-archive.md)._

- **`fleet-rollout` stages for boot by default, local host last (2026-11-09, session 149, PR #104)** — the run just completed showed that a switch hand-off gets run as `boot` anyway, kernel and initrd changes need a reboot regardless, and rebooting gaming ends the Claude session. So boot is the default, switch is opt-in by naming it, remote hosts are rebooted in a new Step 5b, and gaming goes last with its reboot left pending.
- **Remote dry-run gate is a local build plus `nix copy` (2026-11-09, session 149, PR #104)** — `nixos-rebuild dry-activate --target-host` needs root on the target and polkit denies it for `bosko`, so only evaluation and build can be proven remotely. Remote hand-offs carry `--elevate sudo --ask-elevate-password`.
- **wowaudit MCP as a remote OAuth server, login left imperative (2026-11-09, session 149, PR #103)** — the server uses OAuth 2.1 PKCE with dynamic client registration, so there is no key to put in sops; tokens land in `~/.hermes/mcp-tokens/`, outside the store, so rebuilds keep them. Only the authorization-code flow is offered (no device flow), hence `--flow browser`.
- **Enable Hermes's herdr plugin in Nix, install it imperatively (2026-11-09, session 149, PR #105)** — `herdr integration install hermes` writes the plugin into `~/.hermes/plugins/`, and Hermes plugins are opt-in, so the Nix side only lists `herdr-agent-state` in `plugins.enabled`. Same split as PR #101: herdr owns its own files.
- **Land #104 and #105 without `land-prs`'s order prompt (2026-11-09, session 149)** — the user said to land both once green and they were independent PRs on `main`; #105's check was still running, so it was waited out first.
